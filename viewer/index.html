EVIDENCE / ZURICH URBAN MAV

Know what the numbers mean.

The saved run separates camera-path accuracy, global positioning and visual reconstruction quality.

Evaluation JSON
ACCURACY

Camera motion is one part of the model.

The latest experiment evaluates 90 reconstructed camera positions: 0.397 m after global rotation, translation and scale alignment; 8.649 m in absolute coordinates. The aligned score removes global errors using the reference. Ground truth was used only for scoring, never construction.

It does not establish sub-metre surface accuracy. A spatial comparison against a surveyed point cloud or measured control points is still required.

SIH specifies spatial accuracy ≤1 m. The supplied statement does not define the evaluator’s exact error metric.

APPEARANCE

Earlier appearance experiment.

These archived comparisons belong to the earlier 180-view Gaussian-splat experiment. The current 90-view mesh uses actual camera-image textures, not these renders. Neither image realism nor PSNR proves spatial accuracy.
